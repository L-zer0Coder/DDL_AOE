| 项    | 内容              |
| ---- | --------------- |

| 适用范围 | 反攻阶段的整体节奏控制     |

### 1.2 关键细节

## 二、集结阶段

### 2.1 集结函数的启动依据

| 项     | 内容                            |
| ----- | ----------------------------- |
| 目标    | 在合适的时间点启动集结                   |
| 适用范围  | 集结函数（必须编写）                    |
| 启动依据  | **军队规模** + **帧数**             |
| 帧数参考值 | 一般在**防御过第三波之后**，**24000 帧左右** |

**执行步骤**

1. 编写集结函数（原文明确：集结函数是必须写的）。
2. 按"军队规模"与"帧数"两个依据启动调用。
3. 帧数上的参考点是：防御过第三波之后、24000 帧左右。

**关键细节**

- 启动调用的两个依据是并列给出的：军队规模、帧数。
- "24000 帧左右"是原文给出的参考数量级，用于说明时机落在"防御过第三波之后"。

---

### 2.2 集结点的确定方法

| 项    | 内容            |
| ---- | ------------- |
| 目标   | 确定一个可供全军集结的位置 |
| 适用范围 | 集结点坐标的求解      |
| 方法   | 原文称为"一个简单的技巧" |

**执行步骤**

1. **派人探路**。
2. 在探路过程中**记录位置信息**，来源有两种：
   - 被攻击的位置；
   - 视野内出现敌军的位置。
3. 把记录下来的位置**存进全局变量**。
4. 将该位置**向后（即你自己的主营方向）退后几格**。
5. 退后得到的这个位置，就是**集结点**。

**关键细节**

- 位置信息来源有两类（被攻击的位置 / 视野内出现敌军的位置），原文以"或者"并列。
- 记录载体是**全局变量**。
- 退让方向是**向自己的主营方向**。
- 退让距离是**几格**（原文未给出具体格数）。

---

### 2.3 为什么单一集结点不够用

| 项    | 内容                 |
| ---- | ------------------ |
| 目标   | 说明只用一个集结点无法完成集结的原因 |
| 适用范围 | 集结位置的设置方式          |
| 根本原因 | 引擎核心特性             |

**关键细节**

- 原文指出的核心特性是：**位置附近站满人则认为不可达，发命令人不动**。
- 因此：**单一集结点对于集结是不够的**。

---

### 2.4 集结区域的做法

| 项    | 内容                     |
| ---- | ---------------------- |
| 目标   | 让全军能够实际到位，而不是因拥挤导致命令无效 |
| 适用范围 | 集结区域的开辟与维持             |
| 做法   | 以集结点为中心，开辟一个区块         |

**执行步骤**

1. 以**集结点为中心**。
2. 弄一个 **3×3 至 5×5** 的区块。
3. **每个点去一个兵**。
4. 攻击开始后，**军队会移动**，集结点随之**空出来**。
5. 空出来的位置**可以循环填入**。

**关键细节**

- 区块尺寸范围：**3×3 ~ 5×5**。
- 分配粒度：**每个点一个兵**。
- "循环填入"的前提是：攻击开始后军队会移动、集结点会空出，空出的位置可以再次填入。

---

### 2.5 进攻的启动条件

| 项    | 内容                     |
| ---- | ---------------------- |
| 目标   | 判断何时可以开始进攻             |
| 适用范围 | 集结完成到进攻之间的转换           |
| 条件   | 祭司抵达集结区域 **且** 周边有足够兵力 |

**执行步骤**

1. **祭司抵达集结区域**。
2. 祭司的站位：为了安全，**可以放在集结区域里离敌人最远的一格**。
3. 确认**周边有足够兵力**。
4. 满足以上条件后，**就可以进攻了**。

**关键细节**

- 祭司站位是"为了安全"考虑，位置为**集结区域中离敌人最远的一格**。
- "周边有足够兵力"是进攻启动的必要条件之一（原文未给出"足够"的具体数值）。

## 三、拉扯战术

### 3.1 前提认知

| 项    | 内容               |
| ---- | ---------------- |
| 目标   | 明确进攻的正确形态，避免无脑冲锋 |
| 适用范围 | 所有军队配置           |

**关键细节**

- **进攻不是让一堆人都冲进敌人主营。**
- 敌方主营实力：**31 兵、5 箭塔**，其中包括 **4 个投石车**；**实力比玩家强很多**。
- **无论你的军队配置如何，都需要拉扯战术。**

---

### 3.2 拉扯四步循环

| 项    | 内容               |
| ---- | ---------------- |
| 目标   | 通过进退回合的往复，逐步消耗敌方 |
| 适用范围 | 反攻阶段的部队行动        |
| 结构   | 四步循环             |

**步骤 1 — 选择突击者**

- 选择**最靠近敌方角落的军队**作为**突击者**。
- **记录其初始坐标**。

**步骤 2 — 前进与撤回的判据**

- **前进**：如果突击者**距离 n 格内没有敌军**，将突击者**向敌人方向移动**。
- **撤回**：如果突击者**被军队攻击**，或者**距离 n 格内有敌军**，则**向初始位置移动**。
- **协同**：突击者移动时，**其他部队向敌方角落移动 1~2 格**。

**步骤 3 — 归位与身份取消**

- 突击者**回到初始位置**后：
  - **取消突击者标志**；
  - **作为正常的军队参战**。

**步骤 4 — 循环条件**

- 当 **`info` 中没有敌军**时，**回到步骤 1**。

**关键细节**

- 突击者的选择判据是"**最靠近敌方角落**"。
- 记录的是"**初始坐标**"，撤回的目标就是它。
- 前进/撤回的分界是 **n 格内有敌军** 或 **被攻击**（两者满足其一即撤回）。
- n 的取值原文未给出具体数值。
- 其他部队的配合动作是"向敌方角落移动 **1~2 格**"。
- 回到初始位置后，突击者身份被取消，转为普通参战部队。
- 回到步骤 1 的触发条件是"`info` 中没有敌军"。

---

### 3.3 异常处理：突击者死亡

| 项    | 内容           |
| ---- | ------------ |
| 目标   | 突击者阵亡时恢复拉扯循环 |
| 适用范围 | 拉扯进行中        |

**执行步骤**

- 如果突击者死亡，**回到步骤 1**，**重新选择突击者**。

## 四、军队配置与胜利时间

### 4.1 综合军队

| 项    | 内容                      |
| ---- | ----------------------- |
| 构成   | 视频演示的**步、弓、骑组合**        |
| 科技   | **升好攻防技术**（或者**边打边升级**） |
| 状态要求 | **兵强马壮**                |
| 适用判断 | **最稳妥**的打法              |

**集结时的排布**

- **骑兵、步兵靠近敌人**；
- **弓兵在后排**。

**战斗时的要求**

- **连打带射**。
- **复合弓优先攻击范围内的远程兵**，以免祭司被打。
- **祭司转换敌人，优先转换生命值最高的**，最大程度削弱敌人、增强己方。

**战斗过程与收益**

- 战斗过程往往是 **2~3 分钟**。
- 祭司可以转换 **5~6 个**敌军，还是非常可观的。

**代价**

- 综合兵种**消耗资源比较多**，**攒兵的时间略长**。
- 即使发展不慢，战斗结束也要到 **30000 帧（20 分钟）以上**。

---

### 4.2 复合弓手为主的打法

| 项    | 内容                           |
| ---- | ---------------------------- |
| 特点   | **造兵快**                      |
| 科技   | **不用升级攻防技术**                 |
| 理由   | 弓箭手的防御也不需要，**控制好不被近战打是最有效的** |
| 理想用时 | **27000 帧（18 分钟）左右**胜利       |

**前排来源**

- 前排主要靠**祭司转换的骑兵和方阵**。
- 战斗开始前可以有 **3~5 个**（第 2、3 波防御时转换的）。
- 战斗开始后**还可以继续转换**。

**执行要点**

- **控制好战斗距离**，打赢也并不难。

**风险**

- 如果**没控制好距离**，**被敌人十几个近战兵近身**了：
  - 那积攒的主力**很快会死完**；
  - **反而会慢或失败**。

---

### 4.3 收尾与胜利

**拉扯的作用**

- **拉扯技术基本可以保障后排不被投石车攻击。**

**清剿顺序**

1. **将其他军队消灭**之后；
2. 剩余的**两位数复合弓**，加上**祭司**，**消灭 4 个投石车**还是不难的。

**胜利动作**

- 然后（**或者同时**），就是**祭司冲锋转换攻城车厂**，**获得胜利**。

**祭司冲锋的两种情形**

| 情形             | 做法                           |
| -------------- | ---------------------------- |
| **祭司满血**       | 能抗几轮箭塔射击                     |
| **不满血，或者箭塔密集** | 靠**军队吸引火力**，或者**干脆拆掉两三个再进去** |
